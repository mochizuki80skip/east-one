# East One 現場サポート

機能訓練型デイサービスの現場業務（残業の主因）を減らすための Web システムです。
本リリースでは次の 2 つを **1 つのシステム・1 つのデータベース** で扱います。

| 機能 | できること |
| --- | --- |
| 日々のスケジュール | 出勤スタッフと出席者を選び、**ワンクリックで送迎担当・整体担当を自動割り当て**（前回と同じ担当を避ける／同じ便の重複なし／負荷平準化）。手動で微調整して保存・印刷。 |
| 月次報告 | 日々のスケジュールで書いた「今日の様子メモ」が利用者ごとに自動で集まる。キーワード・箇条書きを入力して **ワンクリックで文章化**（Claude API。未設定時は簡易テンプレート）。編集・保存・コピー・印刷。 |
| マスタ | 利用者（介護度・利用曜日・送迎コース・整体有無）、スタッフ（運転可・整体可）、送迎コース（迎え/送り・便） |

日々のスケジュールに出欠を記録するため、ホーム画面に「日別の利用人数・お休み人数」が自動集計されます。
将来の日報（スプレッドシート）置き換えはこのデータを土台に拡張できます。
個別機能訓練計画書は今回のスコープ外です。

## 動かし方

前提: Node.js 22 以上

```bash
npm install
cp .env.example .env      # ANTHROPIC_API_KEY を設定すると AI 文章生成が有効になります
npm run dev               # http://localhost:3000
```

本番運用（事業所内の PC や小さなサーバー 1 台で動きます）:

```bash
npm run build
npm start
```

初回はホーム画面の「サンプルデータを投入する」で動作確認できます。実運用時はサンプルを削除して、利用者・スタッフ・送迎コースを登録してください。

データは SQLite ファイル（既定: `data/east-one.db`）に保存されます。バックアップはこのファイルをコピーするだけです。

## 日々のスケジュールの使い方

1. 「日々のスケジュール」を開く（既定は今日。日付は前後移動・カレンダーで変更可）
2. 出勤スタッフをタップして選ぶ
3. 利用者の出欠を確認（利用曜日から自動で「出席」になっています。お休みの方はタップして変更）
4. 「⚡ 自動割り当て」を押す
   - 送迎: 各コースに運転可のスタッフを割り当て。**前回そのコースを運転した人は避け**、同じ便のコースは別の人に、直近 2 週間の運転回数が少ない人を優先
   - 整体: 整体対象の出席者に整体可のスタッフを割り当て。**その利用者の前回担当と同じ人は避け**、当日の担当数と送迎担当数が少ない人を優先
5. プルダウンで微調整 →「未定の枠だけ割り当て」で固定した枠以外を再計算することも可能
6. 「今日の様子メモ」に一言入れて「保存」（このメモが月次報告の材料になります）

## 月次報告の使い方

1. 「月次報告」→ 対象月 → 利用者を選ぶ
2. 左に日々の記録（出欠・整体担当・メモ）が並びます
3. キーワード欄に単語や箇条書きを入力し「✨ 文章を生成する」
4. 右の本文を確認・修正して「保存」。「本文をコピー」で既存の Excel／スプレッドシートに貼り付けられます

`ANTHROPIC_API_KEY` が未設定、または API エラー時は、記録から組み立てる簡易テンプレート文で生成します（システムは止まりません）。

## 技術構成

- Next.js 16（App Router / Server Actions）+ TypeScript + Tailwind CSS
- SQLite（better-sqlite3）— サーバー不要の単一ファイル DB
- Claude API（`@anthropic-ai/sdk`、モデル `claude-opus-5`）— 月次報告の文章生成

```
src/
  lib/assign.ts        自動割り当てロジック（純粋関数・テスト付き）
  lib/report-text.ts   月次報告の文章生成（Claude + テンプレート）
  lib/repo.ts          DB アクセス
  lib/db.ts            スキーマ定義・接続
  app/actions/         Server Actions
  app/schedule/[date]  日々のスケジュール画面
  app/monthly/         月次報告画面
  app/{clients,staff,courses}  マスタ管理
```

テスト: `npm test`（割り当てロジックのユニットテスト）
