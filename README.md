# East-one 業務サポート

機能訓練型デイサービス East-one の現場業務（残業の主因）を減らすための Web システムです。
本店・三島店・長泉店など複数店舗を、1 つのシステムで店舗を切り替えて使います。

## できること

| 機能 | 内容 |
| --- | --- |
| スタッフ登録 | ステータス（在籍・休職・退職）、資格・役職、勤務形態 A〜D、できること（運転・添乗・整体・個別機能訓練など複数選択）、週の勤務日数、勤務できる店舗・曜日。現行シフト表からの貼り付け取り込みに対応。 |
| シフト作成 | 現行シフト表と同じ記号（〇・休・有・午前・午後・前有・後有・希休・日・①〜④）。希望休・有給を入れて「自動作成」すると、週の勤務日数・必要人数・看護師と機能訓練指導員の最低人数を満たす案を作ります。手直し後に保存。人数不足の日は赤表示。 |
| 曜日別利用者枠表 | 月〜土 × 午前・午後の利用者一覧（介護度・性別・年齢・新規再開）、空き枠と稼働率。スプレッドシートの「曜日別出席リスト」を貼り付けて一括取り込み。 |
| 店舗設定 | 定員、人員基準、定休日、時間割の時刻、車両（乗車可能人数・運転可能スタッフ）、送迎ルート（既定の車両・便ごとの時刻）、お問い合わせ先。 |
| 日々のスケジュール | 曜日別枠から出席予定を作り、お休み（理由つき）・臨時利用を反映。「自動作成」で朝・昼・帰りの送迎（車両・運転者・乗車順・時刻）と個別機能訓練・整体の時間割（担当）を作ります。前回と同じ担当を避け、負荷を平準化します。手直し後に保存し、A4 横で印刷・PDF 保存。 |
| 月次報告 | 担当ケアマネごとに利用者を一覧。日々の「様子メモ」とキーワードから報告文を作成（Claude API、未設定時は簡易テンプレート）。ケアマネ単位で、店舗名・利用者ごとの文章・空き情報・お問い合わせ先の書式で PDF 出力。 |
| 売上日報への転記 | 日報はスプレッドシートが正です。日々のスケジュール画面で利用人数・お休み人数・介護度別・お休み理由を日報の列順でコピーできます。 |

## 使い始める手順

1. 店舗一覧で店舗を追加し、「店舗設定」で定員・人員基準・車両・ルートを登録
2. 「スタッフ」で登録（シフト表の A〜D 列を貼り付けて取り込み可）し、できることを設定
3. 「ケアマネ」を登録
4. 店舗の「曜日別利用者」で曜日別出席リストを貼り付けて取り込み、利用者ごとに担当ケアマネ・送迎ルート・ルート内の順番を設定
5. 「シフト」で希望休を入れて自動作成 → 保存
6. 毎日「日々のスケジュール」で出欠を確認 →「自動作成」→ 手直し → 保存 → 印刷
7. 月末に「月次報告」で文章を作成 → ケアマネごとに PDF 出力

動作確認用に、店舗が無い状態のホーム画面から架空のサンプルデータを投入できます。

## 起動方法

前提: Node.js 22 以上

```bash
npm install
cp .env.example .env    # 必要に応じて ANTHROPIC_API_KEY / APP_PASSWORD を設定
npm run build
npm start               # http://localhost:3000
```

開発時は `npm run dev`、テストは `npm test` です。

データは SQLite ファイル（既定: `data/east-one.db`）に保存されます。バックアップはこのファイルのコピーです。
複数店舗から使うには、ファイルを保存できるサーバー（常時起動の VM や永続ディスク付きのホスティング）に置き、`APP_PASSWORD` を設定してください。

## 技術構成

- Next.js 16（App Router / Server Actions）+ TypeScript + Tailwind CSS
- SQLite（better-sqlite3）
- Claude API（`@anthropic-ai/sdk`）— 月次報告の文章作成

```
src/lib/shift-auto.ts   シフト自動作成（テスト付き）
src/lib/transport.ts    送迎計画（テスト付き）
src/lib/timetable.ts    機能訓練・整体の時間割（テスト付き）
src/lib/import.ts       スプレッドシート貼り付けの取り込み（テスト付き）
src/lib/daily-plan.ts   日々のスケジュールの自動作成（上記をまとめる）
src/lib/report-text.ts  月次報告の文章作成
src/lib/repo.ts         DB アクセス / src/lib/db.ts スキーマ
src/app/s/[storeId]/    店舗ごとの画面（daily, shifts, weekly, clients, monthly, settings）
```
