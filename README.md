# East-one 業務サポート

機能訓練型デイサービス East-one の現場業務（残業の主因）を減らすための Web システムです。
本店・三島店・長泉店など複数店舗を、1 つのシステムで店舗を切り替えて使います。

## できること

| 機能 | 内容 |
| --- | --- |
| スタッフ登録 | ステータス（雇用区分: 正社員・時短社員・パート）、勤務時間のパターン（何時〜何時を複数。1つ目がいつもの時間）、在籍状況（在籍・休職・退職）、資格・役職、勤務形態 A〜D、できること（運転・添乗・整体・個別機能訓練など複数選択）、週の勤務日数、勤務できる店舗・曜日。現行シフト表からの貼り付け取り込みに対応。 |
| 更新のお知らせ | メニューの「更新のお知らせ」で、機能の追加・変更の内容と履歴を確認できます。まだ見ていないお知らせがあると NEW が付き、店舗一覧の上にお知らせが出ます（既読はブラウザごと）。 |
| できることの一括登録 | スタッフ一覧の「✅ できることを一括登録」で、全員の運転・整体・体操などを表でまとめてチェック。スタッフを新しく登録したり取り込んだりした後は、この画面へ進みます。送迎・整体の時間割・体操等の自動振り分けはここでチェックした人から選びます。 |
| シフト作成 | 各スタッフの勤務時間（例: 9-13:30）と、現行シフト表と同じ記号（〇・休・有・午前・午後・前有・後有・希休・日・①〜④）。自動作成ではその人のいつもの時間で入り、半日勤務は 0.5 人と数えます。希望休・有給を入れて「自動作成」すると、週の勤務日数・必要人数・看護師と機能訓練指導員の最低人数を満たす案を作ります。希望休は「なるべく休み」で、人数が足りない日だけ出勤にして赤枠で知らせます（有給は必ず休み）。手直し後に保存。人数不足の日は赤表示。 |
| 曜日別利用者枠表 | 月〜土 × 午前・午後の利用者一覧（介護度・性別・年齢・新規再開）、空き枠と稼働率。スプレッドシートの「曜日別出席リスト」を貼り付けて一括取り込み。 |
| 店舗設定 | 定員、人員基準、定休日、時間割の時刻、車両（乗車可能人数・運転可能スタッフ）、送迎ルート（既定の車両・便ごとの時刻）、お問い合わせ先。 |
| ログイン | パスワードでログイン（設定ファイルで指定）。ログインしないとデータは見られません。 |
| 日々のスケジュール | 曜日別枠から出席予定を作り、お休み（理由つき）・臨時利用を反映。「自動作成」で、送迎（朝迎車・昼送車・昼迎車・帰り送車。昼送車と昼迎車は同じ車両・同じ運転者）、整体・個別機能訓練の時間割（午前・午後それぞれ20名分の一覧）、体操・メディカルケアFIT の担当を作ります。前回と同じ担当を避け、負荷を平準化します。 |
| 出勤状況・空きスタッフ | 資格ごとの出勤人数（午前・午後、兼務は両方に数える）を表示。送迎・時間割・体操等の担当が入っていない出勤者を時間帯ごとに割り出し、各自の担当業務を記入できます。 |
| 印刷 | その日のスケジュールを A4 横 1 枚に配置（上段: 日付・出勤状況・休み・特記事項 / 左: 送迎4区分 / 中央: 時間割 午前・午後 各20行 / 右: 体操等の担当・空きスタッフ・担当業務）。PDF 保存も可。 |
| 月次報告 | 担当ケアマネごとに利用者を一覧。日々の「様子メモ」とキーワードから報告文を作成（Claude API、未設定時は簡易テンプレート）。ケアマネ単位で、店舗名・利用者ごとの文章・空き情報・お問い合わせ先の書式で PDF 出力。 |
| 売上日報への転記 | 日報はスプレッドシートが正です。日々のスケジュール画面で利用人数・お休み人数・介護度別・お休み理由を日報の列順でコピーできます。 |

## 使い始める手順

1. 店舗一覧で店舗を追加し、「店舗設定」で定員・人員基準・車両・ルートを登録
2. 「スタッフ」で登録（シフト表の A〜D 列を貼り付けて取り込み可）し、できることを設定
3. 「ケアマネ」を登録
4. 店舗の「曜日別利用者」で曜日別出席リストを貼り付けて取り込み、利用者ごとに担当ケアマネ・送迎ルート・ルート内の順番を設定
5. 「シフト」で希望休を入れて自動作成 → 保存
6. 毎日「日々のスケジュール」で出欠を確認 →「自動作成」→ 手直し → 保存 → 印刷
7. 月末に「月次報告」で文章を作成 → ケアマネごとに PDF 出力

動作確認用に、店舗が無い状態のホーム画面から架空のサンプルデータを投入できます。

## 構成（Xサーバーのレンタルサーバーで動きます）

| 部分 | 技術 | 公開時の場所 |
| --- | --- | --- |
| 画面・シフト/送迎/時間割の自動作成 | Next.js（静的書き出し）+ TypeScript + Tailwind CSS。計算はすべてブラウザで行う | `public_html/` |
| データ保存・ログイン・AI 文章作成 | PHP 8.2 以上（Claude は公式 PHP SDK） | `public_html/api/` |
| データ | MySQL（動作確認用に SQLite も可） | サーバーパネルで作成 |

公開アドレスは https://eastone-data.hachimaru-80skip.com/ です（hachimaru-80skip.com のサブドメイン）。設置手順は [docs/deploy-xserver.md](docs/deploy-xserver.md)、どこに何を置くかは [docs/upload-guide.md](docs/upload-guide.md) にあります。

## 開発・確認

前提: Node.js 22 以上、PHP 8.2 以上、Composer

```bash
npm install
npm run preview   # 書き出して http://localhost:8080 で起動（パスワード: preview、データは SQLite）
npm test          # 自動作成ロジックのテスト
npm run package   # アップロード用一式を dist/public_html と dist/east-one-xserver.zip に作る
```

```
src/lib/shift-auto.ts   シフト自動作成（テスト付き）
src/lib/transport.ts    送迎計画（テスト付き）
src/lib/timetable.ts    整体・機能訓練の時間割（テスト付き）
src/lib/staffing.ts     資格別の出勤人数・空きスタッフ・体操等の担当（テスト付き）
src/lib/import.ts       スプレッドシート貼り付けの取り込み（テスト付き）
src/lib/daily-plan.ts   日々のスケジュールの自動作成（上記をまとめる）
src/lib/data.ts         データの読み書き（PHP API を呼ぶ）
src/app/store/          店舗ごとの画面（daily, shifts, weekly, clients, monthly, settings）
server/                 PHP（index.php: API / report.php: Claude / config.sample.php: 設定見本）
scripts/package.sh      アップロード用一式の作成
```
