# 資料の管理画面（運営推進会議の議事録など）

ホームページに、運営推進会議の議事録などの資料を**あとから自分で追加・差し替え**できる画面です。
追加した資料は、公開ページ **https://east-one.hachimaru-80skip.com/documents.html**（公開資料）に自動で並びます。トップページのフッターからもリンクしています。

| 種類 | 公開ページでの見出し |
| --- | --- |
| 運営推進会議 議事録（本店） | 運営推進会議 議事録 ＞ 本店 |
| 運営推進会議 議事録（長泉店） | 運営推進会議 議事録 ＞ 長泉店 |
| 重要事項説明書・運営規程 | 重要事項説明書・運営規程 |
| 処遇改善（職場環境等要件） | 処遇改善に関する取り組み |

運営推進会議は地域密着型の本店・長泉店だけが対象のため、三島店の欄はありません。資料がない種類は「準備中」と表示されます。

## 最初に1回だけやること（設置）

1. アップロード用の zip の中身を、いつもどおり `east-one` フォルダにアップロードします（`kanri` フォルダと `files` フォルダが増えています）。
2. Xサーバーの「ファイル管理」（または FTP）で `east-one/kanri/` を開き、**`config.sample.php` をコピーして `config.php` という名前**にします。
3. `config.php` を編集し、`'password' => 'ここにパスワードを入れる'` の部分を**10文字以上のパスワード**に書き換えて保存します。
   - 例：`'password' => 'Eastone-kanri-2026!',`（実際は推測されにくいものに）
   - このパスワードを知っている人だけが資料を追加・削除できます。共有する相手は最小限にしてください。
4. ブラウザで **https://east-one.hachimaru-80skip.com/kanri/** を開き、パスワードでログインできれば完了です。
5. 念のため、次の2つのアドレスを開いて「Forbidden（403）」と表示されることを確認してください（設定ファイルや管理用データが外から読めないことの確認です）。
   - https://east-one.hachimaru-80skip.com/kanri/config.php → 403 または真っ白
   - https://east-one.hachimaru-80skip.com/kanri/data/ → 403

> 管理画面のアドレスはどこにもリンクしておらず、検索エンジンにも載らない設定です。ブックマークしておいてください。

## 資料を追加する

1. https://east-one.hachimaru-80skip.com/kanri/ にログイン
2. 「資料を追加する」で次を入れて「登録する」
   - **種類**：運営推進会議 議事録（本店）など
   - **タイトル**：ホームページにそのまま表示されます（例：2026年度 第2回 運営推進会議 議事録）
   - **日付**：開催日・作成日。新しい日付が上に並びます
   - **登録のしかた**：どちらか
     - **ファイルを選ぶ**：PDF・Excel（xlsx / xls）・Word（docx / doc）。20MBまで
     - **Google のリンクを貼る**：Google スプレッドシート・ドキュメントの共有リンク
3. 「登録しました」と出たら、公開ページにすぐ表示されています。

### どの形式で載せるのがよいか

| 形式 | 見る人の画面 | おすすめ度 |
| --- | --- | --- |
| **PDF** | スマホでもパソコンでも、そのまま開いて読める | ◎ いちばんおすすめ |
| Google ドキュメント・スプレッドシート | ブラウザで開ける。**共有設定を「リンクを知っている全員（閲覧者）」にする必要あり**。設定を変えると見られなくなる | ○ |
| Excel・Word | ダウンロードになる。スマホでは開けないことがある | △ |

Excel・Word・Google ドキュメントは、それぞれ「ファイル」→「PDF として保存（ダウンロード）」で PDF にできます。PDF にしてから登録すると、ご家族やケアマネージャーが見やすくなります。

### 登録する前に必ず確認
- 利用者様・ご家族のお名前、住所など、**個人が特定される情報が入っていないか**（議事録は特に注意）
- 社内向けのメモやコメントが残っていないか（Word・Excel の「コメント」「変更履歴」も含む）

## 修正・非公開・削除

「登録済みの資料」の各資料の下にある「編集・非公開・削除」を開きます。

- **変更を保存**：タイトル・日付・種類を直せます（ファイルの差し替えは、新しく登録してから古いほうを削除）
- **非公開にする**：公開ページから消えますが、管理画面には残ります。もう一度「公開する」で戻せます
- **削除する**：ファイルごと消えます。元に戻せません

## うまくいかないとき

| 表示 | 対処 |
| --- | --- |
| config.php がありません | 「最初に1回だけやること」の2〜3を行う |
| パスワードを続けてまちがえたため、15分間ログインできません | 15分待ってから、もう一度 |
| ファイルが大きすぎてサーバーが受け取れませんでした | サーバーパネル「php.ini設定」で `upload_max_filesize` を `20M`、`post_max_size` を `25M` にする。または PDF を小さくする |
| ファイルの中身が拡張子と合っていません | 一度開いて「名前を付けて保存」し直してから登録 |
| Google のリンクを開くと「アクセス権が必要です」 | Google 側の「共有」→「一般的なアクセス」を「リンクを知っている全員」にする |

## ホームページを更新（再アップロード）するとき

アップロード用の zip には、**登録した資料やパスワードの設定は入っていません**。zip の中身を上書きアップロードしても、登録済みの資料・`config.php` は消えません。

ただし、サーバー上の次のフォルダ・ファイルは**削除しないでください**（登録した資料が消えます）。
- `east-one/files/` の中身
- `east-one/kanri/data/` の中身
- `east-one/kanri/config.php`
