# アクセス解析（クリック率などの分析）の始め方

ホームページには、Google アナリティクス 4（GA4）と Microsoft Clarity の計測コードが組み込み済みです。
**ID を2つ入れてアップロードするだけで計測が始まります。** どちらも無料です。

| ツール | わかること |
| --- | --- |
| **GA4** | 何人来たか、どこから来たか（検索・LINE・Instagram など）、電話・LINE・ボタンが何回押されたか、どのセクションまで読まれたか。期間比較や店舗別の集計 |
| **Clarity** | ページのどこがどれだけクリックされたかを色で表示（ヒートマップ）、どこまでスクロールされたか、実際の操作の録画。**ボタンごとのクリック率を一番手軽に見られるのはこちら** |

GA4 は設置した日からのデータしか取れません。公開と同時に入れてください。

---

## 1. GA4 の測定IDを取る

1. 会社の Google アカウントで https://analytics.google.com/ を開き、「測定を開始」。
2. アカウント名：`株式会社Breams` など
3. プロパティ名：`East-one ホームページ`、タイムゾーン：日本、通貨：日本円
4. ビジネスの説明は適当に選び、「ビジネス目標」は「見込み顧客の獲得」を選ぶ
5. データ収集で「ウェブ」を選び、URL に `https://east-one.hachimaru-80skip.com`、ストリーム名に `ホームページ` を入れて作成
6. 表示される **測定ID（`G-` で始まる）** を控える
   - 「拡張計測機能」はオンのままで構いません（ページのスクロール率・外部リンクのクリックも自動で取れます）
   - 次の画面で表示される「タグの実装手順」は不要です（コードは組み込み済み）

## 2. Clarity のプロジェクトIDを取る

1. https://clarity.microsoft.com/ に Microsoft アカウントか Google アカウントでログイン
2. 「New project」で名前 `East-one ホームページ`、サイトの URL `https://east-one.hachimaru-80skip.com` を入れて作成
3. 「Install tracking code」の画面は閉じてよい（コードは組み込み済み）。Settings → Overview の **Project ID** を控える
4. Settings → Setup の「Google Analytics integration」で GA4 とつなぐと、Clarity の録画を GA4 側からも探せるようになります（任意）

## 3. ID を入れてアップロードする

`homepage/public_html/analytics.js` の先頭2行に ID を入れます。

```js
var EASTONE_GA4_ID = 'G-XXXXXXXXXX';   // 1. で控えた測定ID
var EASTONE_CLARITY_ID = 'abcd123456'; // 2. で控えたProject ID
```

サーバーの `east-one/` フォルダに **`analytics.js` だけを上書きアップロード**します（全ページがこのファイルを読み込んでいるので、HTML の上書きは不要です）。

## 4. 動いているか確認する

1. スマホかパソコンで `https://east-one.hachimaru-80skip.com/?debug=1` を開き、電話番号や LINE ボタンを押してみる（電話は発信前にキャンセルで可）
2. GA4 の「管理」→「DebugView」に、押した順に `tel_tap` などが出れば成功
3. GA4 の「レポート」→「リアルタイム」にも数秒〜1分で出ます
4. Clarity は反映まで約2時間かかります。翌日に「Recordings」に録画が出ていれば成功

## 5. GA4 で最初にやっておく設定（1回だけ）

**(1) 問い合わせにつながる操作を「キーイベント」にする**
「管理」→「データの表示」→「イベント」で、次の3つの右側の星をオンにします（一度その操作が計測されると一覧に出ます）。
- `tel_tap`（電話番号のタップ）
- `line_click`（LINE 友だち追加ボタン）
- `trial_click`（見学・無料体験ボタン）

レポートの「キーイベント」「キーイベント率」に、問い合わせにつながった割合が出るようになります。

**(2) パラメータを「カスタム ディメンション」に登録する**
「管理」→「データの表示」→「カスタム定義」→「カスタム ディメンションを作成」で、次の4つを登録します（範囲はすべて「イベント」）。

| ディメンション名（表示名） | イベント パラメータ |
| --- | --- |
| 店舗 | `store` |
| 押された場所 | `link_location` |
| リンクの文字 | `link_text` |
| セクション | `section` |

これで「どの店舗の電話が多いか」「ヘッダーのボタンとヒーローのボタン、どちらが押されているか」を集計できます。登録した日以降のデータが対象です。

**(3) データの保持期間を延ばす**
「管理」→「データの収集と修正」→「データ保持」で「イベントデータの保持」を **14か月** にします（初期値の2か月だと、前年同月との比較ができません）。

**(4) 社内からのアクセスを除外する（任意）**
スタッフが確認で開いた分が混ざらないよう、「管理」→「データストリーム」→ ストリーム →「タグ設定を行う」→「内部トラフィックの定義」に各店舗・本社の IP アドレスを登録し、「データフィルタ」で「内部トラフィック」を有効にします。

## 計測しているイベント

| イベント名 | いつ送られるか | 主なパラメータ |
| --- | --- | --- |
| `tel_tap` | 電話番号をタップ | `store`（本店／三島店／長泉店）、`link_location` |
| `line_click` | 公式LINE のボタン・リンク | `link_location` |
| `trial_click` | 「見学・無料体験」へ移動するボタン（ヘッダー・ヒーロー・ケアマネ欄） | `link_text`、`link_location` |
| `instagram_click` | Instagram へのリンク | `link_location` |
| `nav_click` | メニュー・2つの入口・重要事項ページなど、サイト内のリンク | `link_text`、`link_location` |
| `outbound_click` | 運営会社・採用情報など、他のサイトへのリンク | `link_text`、`link_url` |
| `section_view` | トップページの各セクションを1秒以上表示 | `section`（半日型の理由／施設一覧 など） |
| `faq_open` | よくある質問を開いた | `question`（質問文） |
| `float_cta_view` | 追従バナー（見学・無料体験のご案内）が表示された（1ページにつき1回） | `link_location`＝追従バナー |
| `float_cta_close` | 追従バナーを「×」で閉じた（PCのみ） | `link_location`＝追従バナー |

すべてのイベントに `link_text`（押された文字）、`link_location`（押された場所）、`link_url`（リンク先）が付きます（`section_view` を除く）。
同じイベントが Clarity にも送られるので、Clarity の録画を「`tel_tap` があったもの」で絞り込めます。

> 電話は「番号をタップした回数」で、実際に通話したかまではわかりません。LINE も「ボタンを押した回数」で、友だち追加の完了数は LINE 公式アカウントの管理画面で確認します。

## よく見る数字と、その出し方

### ボタン・リンクごとのクリック率（いちばん手軽）
Clarity →「Heatmaps」→ ページを選び「Click」。要素ごとに、クリックされた割合（%）と回数が色で表示されます。スマホ／パソコンを切り替えて見られます。

### 問い合わせにつながった割合（コンバージョン率）
GA4 →「レポート」→「エンゲージメント」→「キーイベント」。
`tel_tap` などの「キーイベント率（セッション）」＝ 訪問のうち、その操作があった割合です。

### 店舗別の電話タップ数、押された場所別のクリック数
GA4 →「探索」→「自由形式」を新規作成し、
- ディメンション：「イベント名」「店舗」「押された場所」「リンクの文字」を追加
- 指標：「イベント数」「総ユーザー数」を追加
- 行に「イベント名」と「押された場所」、値に「イベント数」
- フィルタで「イベント名」が `tel_tap` / `line_click` / `trial_click` のいずれか

クリック率にしたい場合は、同じ期間の `page_view` の「総ユーザー数」で割ります（例：電話タップのユーザー数 ÷ 来訪ユーザー数）。

### 追従バナーのクリック率
GA4 →「探索」→「自由形式」で、フィルタ「押された場所」＝ `追従バナー`、行に「イベント名」、値に「イベント数」。
- 表示回数 ＝ `float_cta_view`
- クリック数 ＝ `trial_click` ＋ `line_click`（押された場所が追従バナーのもの）
- **クリック率 ＝ クリック数 ÷ 表示回数**
- 閉じられた割合 ＝ `float_cta_close` ÷ `float_cta_view`（高ければ、表示のタイミングや大きさを見直す目安）

同じ方法で「押された場所」をヒーロー・ヘッダー・ケアマネージャーの方へ などに変えると、どの位置のボタンがよく押されているかを比べられます。

### どこまで読まれているか（離脱しているセクション）
GA4 →「探索」→「ファネルデータ探索」で、ステップを
1. `page_view`（ページを開いた）
2. `section_view`（セクション＝半日型の理由）
3. `section_view`（セクション＝プログラム）
4. `section_view`（セクション＝利用者様の声）
5. `section_view`（セクション＝施設一覧）
6. `tel_tap` または `line_click`

のように並べると、どこで読むのをやめた人が多いかがわかります。Clarity の「Heatmaps」→「Scroll」でも、どの位置まで何%の人が見たかを確認できます。

### どこから来た人が問い合わせにつながったか
GA4 →「レポート」→「集客」→「トラフィック獲得」で、表の右側のキーイベントを `tel_tap` などに切り替えます。

## チラシ・LINE・Instagram から来た人を見分ける

GA4 は、リンクに「どこから来たか」の印（UTM パラメータ）を付けると、その経路別に集計できます。印がないと LINE や QR コードから来た人は「direct（直接）」にまとめられてしまいます。

| 置き場所 | 使うアドレス |
| --- | --- |
| Instagram のプロフィール | `https://east-one.hachimaru-80skip.com/?utm_source=instagram&utm_medium=social&utm_campaign=profile` |
| 公式LINE のリッチメニュー・配信 | `https://east-one.hachimaru-80skip.com/?utm_source=line&utm_medium=social&utm_campaign=richmenu` |
| チラシ・リーフレットの QR コード | `https://east-one.hachimaru-80skip.com/?utm_source=flyer&utm_medium=print&utm_campaign=2026leaflet` |
| ケアマネ向け資料・FAX の QR コード | `https://east-one.hachimaru-80skip.com/?utm_source=caremanager&utm_medium=print&utm_campaign=fax` |
| Googleビジネスプロフィールの「ウェブサイト」 | `https://east-one.hachimaru-80skip.com/?utm_source=google&utm_medium=organic&utm_campaign=gbp_mishima`（店舗ごとに末尾を変える） |

`utm_campaign` の部分は、配った時期や種類が区別できる好きな名前にして構いません。
GA4 の「集客」→「トラフィック獲得」で、表のディメンションを「セッションのソース / メディア」や「セッションのキャンペーン」に切り替えると経路別に見られます。

## プライバシーについて

`privacy.html` に、GA4 と Clarity を使っていること・Cookie を使うこと・オプトアウトの方法を記載済みです。Clarity の録画では、入力欄の文字などは自動で伏せ字になります（このサイトには入力欄はありません）。
