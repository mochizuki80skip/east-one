# East-one ホームページ

機能訓練型デイサービス East-one（運営：株式会社Breams／80SKIPグループ）の公式サイト。
静岡県東部に3拠点（裾野市・三島市・長泉町）。

**詳しい経緯・事業所データ・残タスクは `HANDOFF.md` を読むこと。**
作業前に必ず目を通す。

## 構成

静的HTML。フレームワーク・ビルドツールなし。サーバーに置くものは `public_html/` にまとめてある。
設置手順は `README.md`。

- `public_html/index.html` … トップページ。CSSとJSを内包
- `public_html/juyojiko.html` … 重要事項・運営規程／処遇改善／運営推進会議（法定掲載）
- `public_html/privacy.html` … プライバシーポリシー
- `public_html/documents.html` + `docs.js` … 公開資料（運営推進会議 議事録など）。`files/documents.json` を読んで並べる
- `public_html/kanri/index.php` … 資料の管理画面（PHP・パスワード認証）。使い方は `docs/kanri.md`。登録データは `kanri/data/`・`files/` にあり、サーバーにだけ置く（Git にも zip にも入れない）
- `public_html/analytics.js` … アクセス解析（GA4・Clarity）。全ページ共通。イベント一覧と設定手順は `docs/analytics.md`
- `public_html/404.html` / `sub.css` / `.htaccess` / `robots.txt` / `sitemap.xml` / アイコン類
- `public_html/images/` … 画像一式
- `build_preview.py` … 画像を埋め込んだ確認用ファイルを `preview/` に作る
- `tools/package.py` … 未記入箇所を確認し、`dist/` にアップロード用一式を作る。ファイル名に版を付ける（`East-oneHP_アップロード用_20261124a.zip` / `East-oneHP_確認用_20261124a.html`。日付＋その日の a, b, c…）
- `tools/make_icons.py` … ファビコン・OGP画像を作り直す

**修正してユーザーに送るときは、必ず `python3 build_preview.py` → `python3 tools/package.py` の順に実行し、版付きの2ファイルを送る。`tools/last_version.txt` もコミットする**（ユーザーの希望：どれが最新か分かるように）。

**HTML を編集したら必ず `python3 build_preview.py` を実行して見た目を確認する。**
相対パスの画像はローカルやチャットのプレビューで表示されないため、確認用の埋め込み版が必要。

**公開アドレスは `https://east-one.hachimaru-80skip.com`**（Xサーバー、`hachimaru-80skip.com` のサブドメイン）。
canonical・OGP・構造化データ・robots.txt・sitemap.xml・.htaccess に直接書いてある。ページを増やしたら sitemap.xml にも足す。

`【要記入】` `【要確認】` は未記入の箇所（黄色で表示される）。`tools/package.py` が残数を知らせる。

## 絶対に守ること

### 1. ブランドカラー #D24F93 を変更しない
会社支給の正確な値。`:root` の `--pink` に定義。

白文字とのコントラスト比が3.98:1で、小さい文字では可読性基準（4.5:1）を下回る。
そのため以下の使い分けをしている。**この二段構えを崩さない。**

- `--pink: #D24F93` … 面、罫線、ロゴ、大きい文字
- `--pink-deep: #A83A73` … 小さい文字、ボタン、白背景上の文字、フォーカス表示

ピンク背景のセクション（ヒーロー／ケアマネージャーの方へ／フッター）では
白文字を18px以上にし、ボタンは白地＋濃いピンク文字に反転させる。

### 2. 本文の文字サイズを縮めない
本文17px・行間1.95。高齢のご家族が読む前提。

### 3. ヒーロー見出しのサイズを上げない
ヒーローは大きな写真1枚が5秒ごとに切り替わる（フェード＋ゆっくりズーム、ドットと一時停止ボタン付き）。
見出しは1行ずつ白い帯にして、PCは写真の左下に重ね、スマホは写真の下端に1行目だけ重ねる（顔を隠さないため）。帯は `white-space:nowrap`。
写真を足すときは `.hero-slides` に `<li>` を追加し、顔が隠れないよう `object-position` で位置を調整する。
PC `clamp(28px,3.3vw,40px)` / モバイル（880px以下）`clamp(19px,6vw,30px)`。
帯が写真からはみ出さず、語の途中で改行されないよう、320〜1920pxで確認した結果。上げると崩れる。
見出しの文言を変えたら、同じように全幅で確認すること。

### 4. 利用者様の声を書き換えない
ご本人の発言をそのまま掲載している。言い回しを整えない。
「デイサービスを利用してみての感想」の1問構成で6件（各店2件）。
下の注記「※ご本人の許可を得て掲載しています。感じ方や変化には個人差があります。」も削除しない。

### 5. 他社を下げる表現を入れない
同じ地域のケアマネージャーは他事業所も担当している。
「1日型では入浴に時間を取られる」のような比較は書かない。
`#why`（半日型である理由）は、入浴・食事がないことを自分たちの時間の使い方として
説明する構成。この論旨を崩さない。
`#why` の本文（「なぜ、私たちは半日型なのか。」と4つの理由）は会社から支給された原稿（2026年11月24日）。言い回しを変えない。

## セクションの並び

ヘッダー → ヒーロー（ピンク）→ 2つの入口（ピンク）→ `#concept`（白）→ `#why`（mist）
→ `#program`（白）→ `#flow`（mist）→ `#voices`（白）→ `#trial`（mist）→ `#stores`（白）
→ `#caremanager`（ピンク）→ `#fee`（mist）→ `#faq`（白・よくある質問）→ `#contact`（mist）→ `#group`（白・80SKIPグループ）→ フッター（ピンク・サイトマップ付き）

よくある質問は `<details>` の開閉式。質問を変えたら head の FAQPage 構造化データも同じ内容に直す（Google のルールで本文と一致が必要）。答えには確定している事業所データだけを使うこと。

追従バナー（`#float-cta`）はトップの写真を過ぎると表示し、`#contact` から下では隠す。PC は右下のカード（×で閉じられる）、スマホは画面下のボタン2つ。

白と mist が交互。セクションを増減するときはこの交互を維持する。

## 画像を追加・差し替えるとき

- サイズを揃える。プログラム・利用者様の声・店舗写真は 900×675 または 1000×750 の4:3
- 明るさを揃える。平均輝度147〜152前後に正規化している
- 縦位置の写真は横長に切り出して使う
- EXIFの向き情報が入っていることがあるので `ImageOps.exif_transpose()` を通す
- 利用者様のお顔が写る場合は掲載同意の確認が必要
